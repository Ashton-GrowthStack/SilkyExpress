## How to sync local ↔ GitHub:
1. **After any GitHub changes:** `git pull origin main` 
2. **Before pushing local changes:** `git fetch origin && git status`
3. **Never force push** - always pull first to check for conflicts
4. **Version bumps:**
   - PATCH (1.2.1): Minor bug fixes, style updates
   - MINOR (1.3.0): New features, new sections
   - MAJOR (2.0.0): Major redesign, breaking changes
